# Вклад в Shelter Humanizer

Особенно полезны реальные примеры русских текстов, где правка сломала смысл,
управление/падеж или авторский голос. Удалите личные данные и укажите жанр, режим,
версию приложения, ожидаемое поведение и фактический результат. Для ИИ также нужны
провайдер, точное имя модели и один/два прохода. API-ключи не прикладывайте.

Зависимости runtime не добавляются без конкретной пользы. Предпочтительны небольшие
изменения с проверкой наблюдаемого поведения: сохранение чисел, Unicode, protected atoms,
отсутствие сети офлайн, отсутствие записи ключей, понятный UX.

В виртуальном окружении установите `pip install -e .` и `pip install -r requirements-dev.txt`.
Запустите unittest, Ruff и проверку форматирования, перечисленные в README.
На Linux для GUI нужен дисплей или Xvfb; `SHELTER_REQUIRE_GUI_TESTS=1` запрещает их пропуск.
Сборку Windows проверяйте через `tools/build_release.py` — он запускает готовый EXE.

Не добавляйте «AI score», гарантии обхода детекторов, случайное перемешивание слов
и Unicode-подмены ради уникальности. Полезность оценивается редактурой и сохранением смысла.
