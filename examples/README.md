# Примеры и проверка качества

Все тексты синтетические: суммы, сроки и ссылки не являются реальными обещаниями продукта.
`post_before.txt` содержит U+200B внутри «проверка» и латинскую `p` в «пpоверка».
Emoji, рубль, тире и цитата должны сохраниться. Латинская `p` остаётся до явного
включения опции «Похожие латинские буквы».

`post_after_light.txt` — реальный результат офлайн-редактуры, а не пример ответа ИИ.
Он намеренно скромный: сложные конструкции и грамматику надёжнее менять моделью.
`business_before.txt` и `academic_before.txt` показывают жанровые исключения:
с выбором соответствующего жанра формальные обороты не удаляются автоматически.

Для модели прогоните эти тексты в режиме ИИ и оцените по [протоколу](../docs/EVALUATION.md).
Ответы модели пока не включены: для них нужно фиксировать модель и настройки,
а не выдавать вручную отредактированный текст за результат приложения.
