# Shelter Humanizer 1.1.0

Обновление Windows-приложения для ИИ-редактуры и очистки скрытых символов.
Исправлены недоступная кнопка установки локального ИИ и ожидание длинных ответов.
Дополнительные возможности находятся в настройках, главный сценарий прежний.

## Скачать и запустить

1. В **Assets** скачайте **Shelter-Humanizer-1.1.0-windows-x64.zip**.
2. Закройте старую программу, распакуйте весь ZIP в отдельную папку и откройте
   **Shelter-Humanizer.exe**. Python устанавливать не нужно.
3. Для первого подключения ИИ: **«Выбрать ИИ» → «Установить локальный ИИ»**,
   выберите модель и подтвердите загрузку. В окне есть прокрутка, кнопка закреплена снизу.
4. Вставьте текст, нажмите **«Улучшить текст»**, проверьте результат и скопируйте его.

**Qwen 3.5 4B (`qwen3.5:4b`) выбрана по умолчанию.** Для первой установки нужны
интернет, компоненты Ollama ≈1,4 ГБ и модель ≈3,4 ГБ; желательно 16 ГБ RAM.
Это ориентир, не измеренный минимум. DeepSeek и другие Qwen доступны в мастере.
При обновлении скачанные встроенные модели и сохранённый выбор переиспользуются.

## Исправления и возможности

- **Установка на небольшом экране:** окно мастера можно менять по размеру,
  содержимое прокручивается, основные действия закреплены снизу. Добавлена
  проверка видимости и нажатия кнопки при крупном шрифте.
- **Долгие ответы:** потоковая обработка Ollama и совместимого API, индикация
  работы и отмена. Предел одного прохода 15 минут; предел простоя локального
  подключения 3 минуты, API по умолчанию 60 секунд. Это пределы ожидания, не обещание скорости.
- **Сбой необязательной вычитки:** первая редактура, прошедшая проверку защищённых
  данных, остаётся доступна с предупреждением. Оборванный основной ответ не принимается.
- **Ручная редактура:** поздний ответ ИИ не затирает правки справа без выбора.
  При выходе предлагается сохранить текст; предупреждения обработки сохраняются в отчёте.
- **Свои модели:** тег каталога Ollama, установленная модель или один совместимый
  GGUF-файл. Подключение своей Ollama, LM Studio и API сохранено.
- **Своя инструкция:** изменение на сеанс или явное сохранение, возврат к
  предустановке. Проверки защищённых данных и очистка после ИИ остаются включены.
- **Длинные документы:** явная обработка частями с продолжением после сбоя,
  пока приложение открыто. Части не пропускаются молча; стоимость API может увеличиться.
- **Диагностика:** проверка подключения без генерации, номер сборки и сводка
  без исходника, промпта, API-ключа и личных путей. Полный JSON-отчёт по-прежнему содержит тексты.
- **TXT и проверки:** BOM UTF-8/16/32, выбор старой кодировки по превью,
  предупреждения о сильном сокращении, потере списка и очевидной смене алфавита.

По умолчанию используется режим **«Небольшие правки»** и проверенная инструкция
`precise`. Сравнение промптов опубликовано отдельно; улучшение качества на любых
текстах или у DeepSeek R1 не заявляется.

- **windows-x64.zip:** готовое приложение, русская/английская инструкции и лицензии.
- **skill.zip:** отдельная редакторская инструкция для ИИ-агентов, без приложения.
- **SHA256SUMS.txt / SHA256SUMS-skill.txt:** контрольные суммы соответствующих ZIP.
- Автоматический **Source code (zip)** содержит исходники, без готового EXE.

Сборка не подписана сертификатом; Windows может показать SmartScreen. Проверяйте
источник и SHA256, отключать защиту не требуется. Веса моделей в ZIP не входят,
установка начинается после подтверждения. Своя инструкция сохраняется только
по отдельной галочке, обычным текстом. История текстов и API-ключи автоматически не сохраняются.

Протоколы сбоев и импорта проверены также синтетическими серверами. Это не заменяет
проверку каждой реальной модели, GPU, GGUF и API-поставщика. Часть функций Windows
недоступна на Linux; Linux-бинарник не выпускается. Ответ нужно вычитать: приложение
не измеряет плагиат, не определяет авторство и не гарантирует прохождение AI-детекторов.

## English

Download **Shelter-Humanizer-1.1.0-windows-x64.zip** from Assets, close the old app,
extract into a separate folder and launch the EXE. Python is not required.
Managed models and explicit saved selections are reused. The interface is in Russian;
English instructions are included.

This update fixes the clipped local-setup confirmation button and long-response
handling. It adds custom model selection/download/single-GGUF import, opt-in custom
instructions with reset, explicit document chunking with in-memory resume,
manual-edit conflict protection and diagnostics without texts or keys.
Qwen 3.5 4B and light editing are the defaults. Review the output; model compatibility
and performance vary. The Windows executable is unsigned. Model weights are not bundled.
