# Shelter Humanizer 1.1: план реализации и приёмки

Запрос владельца, 16 октября 2026: применить аудит надёжности, сохранить простой
главный экран, добавить опциональные свои модели и редакторскую инструкцию в настройках.

## Решения

- Ваши Qwen 3.5 4B, небольшой объём правок и исходный SYSTEM остаются предустановками.
- Своя модель: установленная Ollama/API, загрузка тега из каталога Ollama или импорт
  одного совместимого GGUF. Произвольный код и установщики моделей не запускаются.
- Своя инструкция редактирования — расширенная настройка, со сбросом и явным выбором
  сохранения на компьютере. Программная защита данных не отключается.
- Длинные документы обрабатываются частями по явному выбору, без пропуска частей.
- Диагностика не содержит текста, API-ключа или личных путей. Экспорт полного отчёта
  с текстами остаётся отдельным осознанным действием.
- Следующая сборка: 1.1.0rc1, локальный проверочный выпуск. Публикация отдельно.

## Проверяемые этапы

1. Сохранность ручных правок, предупреждений и несохранённых текстов; контроль полноты.
2. Масштабируемые диалоги с видимыми действиями; дополнительные настройки вне главного экрана.
3. Пользовательская инструкция, выбор/загрузка/импорт модели, явное сохранение настроек.
4. Диагностика и причины ошибок, сведения модели, бюджет контекста, структурированная вычитка.
5. Длинные документы с продолжением; потоковый совместимый API; импорт кодировок.
6. Защита от двойного запуска, номер сборки, документация, регрессионные и GUI-тесты,
   новый ZIP и проверка распакованного EXE. Реальное покрытие устройств сообщается отдельно.

## Ход проверки кандидата (история)

- Подготовлен план; прежнее исправление ожидания и его проверки сохранены в checkout.
- Этапы 1–5 реализованы. Проверены свои модели/инструкция, сохранность ручных правок,
  экспорт предупреждений, прокрутка диалогов, SSE, метаданные модели и продолжение
  документа в GUI. 200 тестов прошли на Windows / Python 3.12.14 без пропусков.
- Этап 6: реализованы mutex Windows, безопасная диагностика, идентификатор сборки,
  русский справочник расширенных настроек и английское описание. Проверочный ZIP
  собран отдельно от опубликованного 1.0.0. Распакованный EXE прошёл офлайн GUI-проверку
  и протокольные сценарии на loopback. Публикация не выполнена. Итоги: STATUS.md.


## Стабильный выпуск

Версия 1.1.0 продолжает проверенный кандидат без новых функций. Публикация:
[RELEASING.md](RELEASING.md); исходники, тесты и архивы выпуска привязываются
к одному коммиту, прошедшему GitHub Actions.
