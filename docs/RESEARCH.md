## Вывод

Перефразирование по правилам не заменяет модель. Первый запуск должен работать без модели, но интерфейс честно называет его лёгкой редактурой. Полноценная ИИ-редактура подключает локальную модель Ollama или выбранный пользователем OpenAI-совместимый API. Облачного fallback нет.

Unicode — стандарт для русских букв, тире и эмодзи, а не метка ИИ. Ищем конкретные невидимые, управляющие и смешанные символы. Не удаляем всю не-ASCII типографику. Смешение латиницы/кириллицы — повод проверить слово, а не доказательство ошибки или авторства.

## Дополнительные первоисточники

- [Unicode UTS #39](https://www.unicode.org/reports/tr39/): смешение письменностей и похожие символы. Наш ограниченный сканер не заявляет полное соответствие UTS #39.
- [Python Tkinter](https://docs.python.org/3/library/tkinter.html): GUI без стороннего runtime-фреймворка; Linux может требовать python3-tk.
- [Ollama chat](https://docs.ollama.com/api/chat): локальный POST /api/chat, stream=false, ответ message.content.
- [OpenRouter chat API](https://openrouter.ai/docs/api/api-reference/chat/create-a-chat-completion): совместимый протокол chat/completions. Модель и доступ выбирает пользователь.
- [PyInstaller](https://pyinstaller.org/en/stable/usage.html): Windows-пакет включает интерпретатор и Tk; Linux требует сборки на Linux.
