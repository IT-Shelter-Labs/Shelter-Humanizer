# Проверки Shelter Humanizer

## 1.1.0rc1 · 2026-10-16

После нового сообщения подписчика о недоступном подтверждении установки отдельно
проверен мастер: Tk scaling 1.0/1.5/2.0/2.67 при окнах 640×480/540×400/480×360/480×360.
Один дополнительный регрессионный тест с четырьмя сценариями прошёл: кнопка целиком
находится внутри окна, нажатие открывает подтверждение, отмена не начинает загрузку,
колесо прокручивает содержимое. Это значения Tk, а не проценты масштаба Windows.
Код приложения и ZIP после этих дополнительных проверок не менялись.
По публичной странице Releases на момент проверки Latest остаётся v1.0.0;
исправленный мастер входит в локальный кандидат 1.1.0rc1.

- 200 тестов прошли без пропусков на Windows / Python 3.12.14, включая настоящие
  Tk-окна. Ошибок обработчиков Tk в журнале нет. Ruff и проверка форматирования прошли.
- Добавлены проверки ручных изменений во время ожидания, сохранения предупреждений
  в отчёте, подтверждения замены исходника/выхода, видимости действий при крупном шрифте,
  явного согласия на свою модель и сохранение/сброс пользовательской инструкции.
- Проверены SSE и непотоковый API, сведения модели, JSON Schema вычитки, продолжение
  всех частей документа после сетевого сбоя и после отклонения изменённых чисел.
  GUI также сохраняет старый результат до завершения всех частей.
- Повреждённая конфигурация модели не ломает первый запуск. Личный путь, полученный
  от API вместо имени модели, скрывается из диагностической сводки.
- Четыре теста импорта GGUF используют синтетический файл и loopback-сервер.
  Они проверяют протокол, хеш, отмену и сохранность файла, а не реальную модель.
- Предустановка Qwen 3.5 4B сохранена. SYSTEM совпадает с выбранным evaluated-промптом;
  SHA256 `2d7a20a3b3917178a5bed75b697d73041291dab04d4018dbfd0040548b078a96`.
- Новый реальный прогон моделей и проверка на ноутбуке подписчика не выполнялись.
  Нет утверждения об улучшении качества модели, гарантии AI-детекторов или поддержке
  каждого GGUF, устройства и совместимого API. Сертификата подписи EXE нет.

- ZIP и EXE 1.1.0rc1 собраны с PyInstaller 6.22.3. Распакованный EXE прошёл
  встроенную GUI-проверку без переменных Python/Tcl в пути с кириллицей и пробелами.
  Через loopback-имитатор дополнительно проверены Ollama NDJSON, SSE API,
  сбой вычитки HTTP 503, весь документ свыше 12 000 символов и своя инструкция.
  Внешней сети и реальной модели в этой проверке не было.
- [Сводка проверки и SHA256 архива](../evaluations/reliability-1.1.0rc1/verification.json).
  Идентификатор `1.1.0rc1-20261016T124732Z`; сборка из незакоммиченного checkout,
  публичный выпуск и отправка в GitHub не выполнялись.

Предыдущие результаты ниже относятся к указанным этапам и не подменяют текущие.

## Локальное исправление ожидания Ollama · 2026-10-16

- 159 тестов прошли без пропусков на Windows / Python 3.12.14. Дополнительно
  27 сетевых проверок прошли на Python 3.11.0: длинный ответ после прежнего
  общего таймаута, предел простоя и общий предел генерации, отмена с закрытием
  соединения, разрезанные UTF-8 последовательности, оборванный поток и ошибки сервера.
- Ruff и проверка форматирования прошли. Системный промпт не изменён:
  SHA256 `2d7a20a3b3917178a5bed75b697d73041291dab04d4018dbfd0040548b078a96`;
  `selected.txt` совпадает с `SYSTEM` посимвольно.
- Отдельный Windows EXE собран с Python 3.12.14 / PyInstaller 6.22.3.
  Встроенная офлайн-проверка и проверка распакованного EXE в окружении без
  PYTHONPATH/PYTHONHOME/TCL_LIBRARY/TK_LIBRARY прошли.
- Распакованный EXE обработал синтетический текст на 4652 символа через
  локальный имитатор Ollama. Проверены потоковый запрос, сохранение первой
  редактуры после HTTP 503 во второй вычитке, предупреждение, Unicode-очистка
  и отсутствие тела ошибки сервера в отчёте. Это проверка протокола и приложения,
  не реальная генерация моделью и не оценка её качества.
- Исходный ноутбук подписчика, полный пример его текста и точное время до
  ошибки недоступны. Нехватка RAM/VRAM по скриншотам не установлена.
- Ручная проверка владельцем 16 октября: по его сообщению, на его компьютере
  обработка тестового текста на выбранных моделях занимает до 30 секунд,
  с дополнительной ИИ-вычиткой и без неё ошибок не возникло. Это проверка
  реальной генерации пользователем; точные характеристики устройства и замеры
  по каждой модели не предоставлены. Сценарий медленной генерации на ноутбуке
  подписчика ещё требует повторной проверки тем же исправленным архивом.

Проверочный ZIP: `dist/windows/timeout-fix-2026-10-16/Shelter-Humanizer-timeout-fix-2026-10-16-windows-x64.zip`,
14 332 723 байта. SHA256: `3a4f6687b346cc8df5411b6c47dd7f93ca8691bf71b417b9fc9599179bab9adb`.
Это локальная тестовая сборка из рабочей версии 1.0.0, не новый публичный релиз.
Прежние архивы сохранены; публикация на GitHub не выполнялась.

## Текущая main · 2026-10-05 · Qwen по умолчанию

- Начальный выбор: Qwen 3.5 4B (`qwen3.5:4b`); сохранённые модели не заменяются.
- 147 тестов прошли без пропусков на Windows / Python 3.11 и 3.12.14. Отдельно
  проверены первый запуск без установки, восстановление DeepSeek, сохранение
  произвольной ручной модели и отсутствие подстановки Qwen для API.
- Ruff 0.16.9 и проверка форматирования прошли. Независимый обзор не выявил блокирующих замечаний.
- Windows EXE собран PyInstaller 6.22.3 / Python 3.12.14. Встроенная проверка и
  повторная проверка распакованного ZIP прошли без сети и без окружения Python/Tcl.
  Они подтверждают `default_model=qwen3.5:4b`, `default_depth=edit`, сохранение
  выбранного DeepSeek и точный SHA системного промпта из отчёта.
- Новые генерации моделей и исследование качества не запускались. Защита данных,
  декодирование, параметры генерации и вторая вычитка сохранены.

Локальная проверочная сборка: `Shelter-Humanizer-1.0.0-qwen-default-windows-x64.zip`,
14 327 519 байт. SHA256: `f72ac672db7bf007e5a71ab80619abeac6b36ca409466596d02af846453505b1`.
Архив сохраняется отдельно от первоначального выпуска; его публикация как нового

выдаётся за уже успешный hosted CI. [Порядок публикации](RELEASING.md).
