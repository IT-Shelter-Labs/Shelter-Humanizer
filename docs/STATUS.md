Архив: `Shelter-Humanizer-1.0.0-windows-x64.zip`, 14 332 420 байт.
SHA256: `a684ea4d32b25f7396c9888bab1a3cc5d3b324bb5594c415892f8a7feccb9c91`.
Внутри — EXE, русская/английская инструкции, примеры, лицензии runtime и SELFTEST.json.
Сборка не подписана сертификатом. Весов моделей в архиве нет.

Автоматические проверки ИИ-пайплайна используют синтетические ответы и локальные
HTTP-серверы. Они проверяют свойства программы и не являются реальной генерацией
DeepSeek. Во время финальной автоматической приёмки новые модели не скачивались,
пользовательские тексты не отправлялись внешним сервисам.

После отправки исходников необходимо дождаться GitHub Actions, затем опубликовать
Release и проверить скачивание архива из него. Текущий локальный результат не
выдаётся за уже успешный hosted CI. [Порядок публикации](RELEASING.md).
