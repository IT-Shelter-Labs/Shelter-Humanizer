# Направления развития

Публичная версия 1.0 включает Windows-приложение, локальный мастер ИИ,
редакторский промпт, проверки символов, CLI и отдельный portable skill.
Фактические проверки и ограничения — в [STATUS.md](STATUS.md).

Возможные следующие улучшения, без обещания сроков:

- Согласованный набор русскоязычных примеров и редакторская оценка разных моделей.
- Проверка первого запуска на нескольких устройствах, включая масштаб 125–150%.
- Английская локализация интерфейса; сейчас переведена документация.
- Расширенная приёмка Linux и отдельная упаковка после неё.
- Более удобная диагностика скорости и нехватки памяти локального ИИ.

Изменения должны сохранять содержание, простой первый экран и явный выбор
сервиса. Новый backend, автоматическая история текстов и «процент человечности»
не являются необходимыми направлениями развития.
