# Упрощение интерфейса · 0.1.3

Исследование и решения: 2026-10-04. Источники — авторы рекомендаций и сами продукты.
Это обоснование дизайна, а не результат пользовательского исследования Shelter Humanizer.

## Что делают профессиональные продукты

**Показывают возможности постепенно.** [NN/g: Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/)
предлагает оставлять частые действия на первом экране, а редкие параметры переносить
на следующий уровень. Переход должен быть заметным и иметь понятное название.
Скрывать необходимые сведения вместе с дополнительными настройками нельзя.

**Делают настройку необязательной.** [Grammarly Paragraph Rewriter](https://www.grammarly.com/ai/ai-writing-tools/paragraph-rewriter)
начинается с ввода текста; выбор тона необязателен. [Поддержка Grammarly](https://support.grammarly.com/hc/en-us/articles/30916398193037-Introducing-paragraph-level-rewrites)
описывает действия над выбранным текстом и явное принятие результата. Берём принцип
короткого пути от текста к действию, без заявления о паритете качества с Grammarly.

**Называют поля и действия прямо.** [GOV.UK Text input](https://design-system.service.gov.uk/components/text-input/)
рекомендует видимые короткие подписи и небольшие пояснения, вместо подсказок только
внутри поля. [GOV.UK Step by step navigation](https://design-system.service.gov.uk/patterns/step-by-step-navigation/)
упорядочивает шаги по задачам пользователя. Это применимо к ручному переносу текста
в ИИ-чат: скопировать задание, отправить, вернуть ответ.

## Адаптация для Shelter Humanizer

| Проблема | Решение |
| --- | --- |
| Боковая панель постоянно требует внимания | Удалена; первый экран отдаёт место исходнику и результату |
| Несколько равнозначных действий | «Улучшить текст» — единственная акцентная кнопка; проверки остаются вторичными |
| Длинный список параметров | «Настройки текста»: жанр, тип правок, стиль, важные слова, повторная вычитка и очистка |
| «Голос» воспринимается как звук | «Стиль и важные слова», с примером текста и пояснением |
| «Глубина» непонятна новичку | «Что изменить»: небольшие правки / переписать формулировки; пояснение рядом |
| «Промпт» объясняет механизм, а не задачу | «Обработать в ИИ-чате…», три шага и кнопки копирования задания / вставки ответа |
| Пустые таблицы занимают экран | «Проверки и изменения» открываются в отдельном окне по запросу; явная проверка и смысловые замечания открывают его автоматически |
| На каждом запуске приходится выбирать установленный ИИ | Сохранённый локальный пресет подключается автоматически; новой загрузки нет |
| Повторная вычитка увеличивает ожидание | По умолчанию один проход; второй доступен в настройках |

Режим обработки всегда виден на главном экране. Без ИИ прямо указаны небольшие правки
по правилам; API показывает сервис. Ошибки, отмена и смысловые замечания не скрыты.
Исходник остаётся отдельным, результат можно редактировать и копировать вручную.

Новая шапка: «Естественный текст. Ваш стиль». ИИ-инструкция сохраняет язык исходника.
Русский остаётся основным профилем правил и оценки; другие славянские языки не получают
статус проверенной поддержки из-за изменения подписи. Замена похожих латинских букв
по-прежнему выключена и помечена как настройка для русских слов.

## Что проверяем

Реальные Tk-окна в двух темах; размеры 960×620 и 1366×768; доступность основного действия
и экспорта; сохранение всех параметров; полный ручной сценарий ИИ-чата; защита от вставки
задания вместо ответа и от ответа для прежнего исходника; физические сочетания EN/RU;
готовый EXE без окружения разработчика. Проверка новичком остаётся отдельным следующим шагом.
