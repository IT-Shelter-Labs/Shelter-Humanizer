# Проверка качества редактуры

Автотесты проверяют свойства программы и протоколы HTTP, но не качество любого ответа модели.
До публичного анонса ИИ-режима нужно проверить выбранную модель на реальных русских текстах.
Готового универсального рейтинга или «процента человечности» у проекта нет.

Сравнение шести инструкций на Qwen 3 1.7B, Qwen 3.5 4B/9B и DeepSeek R1 8B
сохранено в [отчёте за 4–5 октября 2026 года](PROMPT_EVALUATION_2026-10-04.md).
В нём есть фиксированный корпус, независимые слепые ИИ-оценки, отложенные тексты,
отдельная проверка двух проходов и все отклонённые попытки. Это машинная оценка
на небольшом синтетическом корпусе; проверка русскоязычными редакторами остаётся полезной.

## Тексты для первого прогона

Три синтетических примера находятся в `examples/`. Затем добавьте хотя бы 2–3 типичных
текста аудитории без персональных данных. Для каждого сохраните исходник, ответ,
точное имя/версию модели, провайдера, дату, жанр, число проходов и замечания редактора.
Используйте каталог `local-evaluation/` (он исключён из Git). API-ключи туда не записываются.

Сделайте два прогона, если сравниваете настройки: один проход и два. Не выбирайте удачный
ответ из множества повторов, выдавая его за обычное качество. Эхо-сервер в тестах проверяет
механизм сохранения, а не качество языковой модели.

## Критерии редактора

| Критерий | Условие принятия |
| --- | --- |
| Факты | Все исходные утверждения, числа, единицы, имена, сроки и ссылки сохранены |
| Оговорки и отрицания | «Может», «примерно», «не доказано» не становятся уверенностью |
| Голос | Тон соответствует жанру/образцу; нет добавленного личного опыта и эмоций |
| Ясность | Меньше пустых подводок, тяжёлых конструкций и повторов; логика читается проще |
| Русский язык | Нет сломанного управления, согласования и неестественных синонимов |
| Защита | Цитаты, код и выбранные термины совпадают буквально |
| Unicode | Легитимные знаки сохранены; оставшиеся находки понятны и видны |

Для каждого критерия отметьте «принято», «нужна правка» или «отклонено» с конкретным фрагментом.
Ответ с искажением факта отклоняется, даже если звучит красиво. Не переносите вывод о
конкретной модели на все модели и жанры.

## Проверка новичком

Человек, который не пользуется терминалом, должен распаковать архив, открыть EXE,
найти пример, получить результат, увидеть U+200B и сохранить TXT без подсказок разработчика.
Отдельно проверьте 1366×768, увеличенный масштаб Windows, длинный текст, ошибку ключа,
недоступную Ollama, отмену и изменение исходника во время сетевого запроса.

Нормальный результат не обязан содержать правки: хороший исходник следует сохранить.

## Локальная проверка 0.1.2

На Windows реально установлена переносимая Ollama 0.35.1 и загружены Qwen 2.5 1.5B/7B.
Полный GUI workflow с 7B и двумя проходами вернул простой синтетический пост, сохранил
исходник и выключил ИИ при закрытии. При этом фраза «Важно отметить» осталась:
редакторская эффективность этого ответа ограничена. На примере с числами, ссылкой
и цитатой обе модели теряли защищённые метки; ответы отклонены без замены результата.
Это аргумент для дальнейшей оценки более сильных моделей и промптов, а не причина
ослаблять проверку сохранения фактов. Полные локальные записи исключены из Git.
