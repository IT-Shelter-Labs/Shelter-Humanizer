# Changelog

## 1.0.0 — первый публичный выпуск

- DeepSeek R1 0528 Qwen3 8B — основной пресет; Qwen 3/3.5 доступны как альтернативы.
- Редакторская инструкция работает с фактами и смысловыми связями целого текста: новая композиция, менее шаблонные начала абзацев и концовки, сохранение всех сведений и оговорок.
- Очистка распознанных нежелательных символов после генерации и вычитки; повторная проверка защищённых данных после очистки. Очистка ответа из внешнего чата также поддерживается.
- Простой Windows GUI, установка локального ИИ после подтверждения, собственный процесс без автозапуска, светлая/тёмная темы, копирование, проверки и экспорт.
- Исправлено искажение длинного русского промпта в буфере Windows; копирование и вставка используют Unicode без потери букв.
- Русский README, английский вариант, инструкция для новичков, лицензии моделей, шаблоны Issues и файлы публичного выпуска.
- Windows portable ZIP и отдельный portable skill. Исходники и CLI доступны для Python 3.11+; Linux-бинарник не выпускается.


## 0.1.5 — local release candidate

- Нейтральный встроенный пример: объявление книжного клуба; искусственные Unicode-находки перенесены в отдельный smoke-test.
- ИИ получает читаемые имена, цитаты, числа и ссылки. Буквальная проверка защищённых фрагментов выполняется после ответа; локальные маски используются только для очистки.
- Глубокая редактура получает рекомендации по конкретным шаблонным местам, а почти неизменённый длинный ответ с такими местами отмечается для пользователя.
- Вторая вычитка предлагает проверяемые исправления отдельных предложений вместо повторной генерации всего текста. Неверный формат, возвращённые подводки и новые распознанные смысловые проблемы сохраняют первую редактуру с явным предупреждением; изменение защищённых данных отклоняет ответ.
- Проверка оговорок дополнена словами «часто», «редко», «во многом», «прежде всего», «в основном». Конечная пунктуация обычной ссылки больше не считается частью адреса.
- Прогон реальной 4B и ограничения качества зафиксированы в `docs/STATUS.md`.

## 0.1.4 — local release candidate

- Qwen 2.5 удалена из мастера. Новые варианты: Qwen 3.5 4B (основной), Qwen 3 1.7B (компактный), Qwen 3.5 9B (крупный).
- Инструкция адаптирована из предоставленного пользователем редакторского задания: работа с текстом целиком, русским синтаксисом, ритмом и абзацами; без случайных синонимов, выдуманных фактов и намеренных ошибок.
- Для Qwen 3/3.5 в Ollama явно отключены рассуждения и задан контекст 16 384 токена; параметры генерации согласованы с официальными рекомендациями для non-thinking режима.
- В GUI по умолчанию включены глубокая переработка, дополнительная вычитка, спецпробелы и NFC; замена похожих букв остаётся отдельным выбором для русского текста.
- Настройки очистки работают и после ИИ-переработки, и при вставке ответа из внешнего чата. Цитаты, ссылки и код защищены, исходник сохраняется.

## 0.1.3 — local release candidate

- Первый экран: два широких поля и основное действие «Улучшить текст». Постоянная боковая панель убрана, дополнительные параметры доступны через «Настройки текста».
- «Голос» заменён на «Стиль и важные слова». Тип правок объяснён через «Небольшие правки» / «Переписать формулировки».
- «Обработать в ИИ-чате…» ведёт через копирование задания, самостоятельную отправку в чат и вставку ответа. Задание вместо ответа и ответ для изменённого исходника не принимаются.
- Таблицы проверок и изменений раскрываются по запросу. Смысловые замечания показываются автоматически.
- Установленная в мастере модель подключается при запуске без повторной загрузки. Вторая вычитка доступна, но по умолчанию выключена.
- Шапка «Естественный текст. Ваш стиль». ИИ-инструкция сохраняет язык исходника; основной профиль офлайн-правил остаётся русским.
- Решения и первичные UX-источники: `docs/UX_RESEARCH.md`.

## 0.1.2 — local release candidate

- Исправлена причина отказа Ctrl+V/C/X/A в Windows: NumLock ошибочно воспринимался как Alt. Реальные нажатия проверены в английской и русской раскладках; редактирование выполняется напрямую без повторных событий Tk.
- Подсказки скрываются при смене окна, открытии диалога, сворачивании и прокрутке; больше не остаются поверх других приложений.
- Колесо прокручивает боковую панель над её кнопками, подписями и настройками.
- Мастер после подтверждения сам скачивает проверенную переносимую Ollama и выбранную модель. Браузер и команды не нужны.
- Собственный ИИ и его дочерние процессы завершаются при закрытии приложения; отдельная установка Ollama не затрагивается. Выбор модели сохраняется для следующего запуска.
- Убрана подпись «Редактор русского текста» из шапки. Логотип, темы и копирование результата сохранены.

## 0.1.1 — local release candidate

- Горячие клавиши редактирования работают в русской и английской раскладках; дополнительная вставка Ctrl+B.

## 0.1.0 — local release candidate

- Windows GUI на русском: исходник/результат, жанры, Unicode, стиль, diff и явный экспорт.
- Светлая/тёмная темы, фирменный логотип IT Shelter и кнопка Telegram; переключение сохраняет текст и правки.

- Защита чисел/цитат/кода/ссылок, отклонение нарушенных меток и замечания по оговоркам.
- Промпт для внешнего чата, CLI и самостоятельный portable skill.
- Проверки GUI/core/протокола, сборка portable Windows ZIP и офлайн self-test готового EXE.
